# 🏦 Bank Management System

A modern **Bank Management System** built using **HTML, CSS, and JavaScript** following the **MVC (Model-View-Controller)** architecture. The application allows users to create bank accounts, perform transactions, and manage account details through a clean and responsive interface.

---

## 🚀 Features

* ✅ Create new bank accounts
* 💰 Deposit money into an account
* 💸 Withdraw money with balance validation
* 📊 Display account information
* 🔒 Private balance using JavaScript private fields (`#balance`)
* 🏗️ Organized MVC architecture
* 📱 Responsive and modern UI
* ✔️ Input validation and error handling

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Architecture:** MVC (Model-View-Controller)
* **Concepts Used:**

  * ES6 Modules
  * Classes & Objects
  * Encapsulation (Private Fields)
  * DOM Manipulation
  * Event Handling
  * Responsive Design

## ⚙️ How It Works

### Model

Handles all business logic and account operations.

* Create Bank Account
* Deposit Money
* Withdraw Money
* Store Account Data
* Balance Management

### View

Responsible for:

* Reading user inputs
* Updating the UI
* Rendering account information
* Displaying alerts and messages

### Controller

Acts as the bridge between Model and View.

* Receives user actions
* Validates data
* Calls Model methods
* Updates the View

---

## ✨ Functionalities

### Create Account

* Enter account holder name
* Enter initial balance
* Generates a unique account number

### Deposit

* Deposit money into an existing account
* Updates available balance

### Withdraw

* Withdraw money
* Prevents withdrawal if balance is insufficient

### Account List

Displays all created accounts dynamically.
